# 拆解方法论：看懂一个对标账号和一条对标视频

> 吸收自 WEILANX 起号教程，以及他开源的 `weilanx-claude-videos/.claude/skills/weilanx-creator-distill-video`（拆解方法.md）。
> 拆解分三层：**账号**（它靠什么活）→ **视频**（这条为什么爆）→ **画面语法**（它长什么样、怎么动）。

---

## 0. 心法（每次开拆前默念）
1. **爆过的会一直爆**：对标是在找"已经被市场验证的东西"，不是找灵感。
2. **学语法，不搬内容**：选题 / 结构 / 节奏 / 画面语法 / 音乐调性可以学；文案、字幕、分镜顺序、水印、角色肖像、原配乐不搬。
3. **每条观察都要带数字**：颜色值、帧数、秒数、百分比。"感觉高级"无法变成代码，"18 帧模糊+透明收入"可以。
4. **先结构后细节**：先看节奏骨架和画面分类，再放大看字体和质感。
5. **多样本找共性**：一条是偶然，三条是风格。一致的进"特征"，不一致的记成"变体"。

## 1. 账号层拆解（15 分钟）

目的：判断这个号**值不值得长期跟**，以及**能抄它什么**。

### 1.1 包装（给系统的标签）
| 项 | 看什么 |
| --- | --- |
| 名字 | 几个字、像不像书名、和知识/思考的关系 |
| 头像 | 主体是什么，在小圆里能不能一眼看清 |
| 背景 | 色调是否和头像一致 |
| 简介 | 一句话定位；有没有系列/更新预告 |

### 1.2 作品矩阵（主页最近 10–20 条）
- **播放分布**：中位数、最高、过万占比。条条过万 ≠ 条条爆，很可能隐藏过低播放的（WEILANX：发 29 藏 19）。
- **题材分布**：按题材归类 → 哪类反复出数据 = 它的"主力题材"。
- **系列化**：有没有固定系列名/编号（如"FPS 科普 第 N 期"）。系列 = 被验证的题材在反复吃流量。
- **风格家族**：画面风格有几种？是否随题材切换？
- **更新节奏**：每天几条、什么时间发。
- **账号年龄 & 粉丝**：粉丝少但播放高 → 爆的是选题，最值得抄。

### 1.3 Top 3 爆款速判
对播放最高的 3 条，各回答一句：
- 标题句式（第二人称？痛点？悬念不给答案？）
- 情绪动机（替自己说话 / 反常识 / 涨知识 / 争论站队）
- 分享率（分享 ÷ 点赞，≥1 说明是转发型）
- 能不能画出来（载体是什么）

### 1.4 账号结论
- 跟不跟：主力题材是否在我定位内、是否还在上升（看最近 3 天的作品数据）。
- 可抄要素：包装 / 题材 / 系列 / 风格 / 标题句式，逐项勾。
- 写进 `benchmarks/accounts.md`。

## 2. 视频层拆解（为什么爆）

### 2.1 选题与钩子
- 前 3 秒说了什么、画了什么？标题条是否从第一帧就在（前 17 秒必须交代主题）。
- 有没有"被冤枉的人 → 翻案"结构。
- 评论区主要争论点 → 我的版本要放大它。

### 2.2 结构时间线
| 要素 | 记录 |
| --- | --- |
| 问题抛出 | 第几秒 |
| 信息点密度 | 平均几秒一个 |
| 高潮 1 / 2 | 第几秒，是否落在配乐大重拍/换气后 |
| 锚词 | 是哪个词，出现在哪几处 |
| 高潮前半句 | 有没有"话说一半——" |
| 结尾问题 | 是否人人都有答案、是否大字挂到片尾 |

## 3. 画面语法拆解（它长什么样、怎么动）

### 3.1 节奏骨架 → 先判风格类型
跑 `scripts/analyze_video.py` 看镜头表 + 运动强度曲线：
| 现象 | 判断 | 该学什么 |
| --- | --- | --- |
| 硬切很少、镜头很长（130s 只有 7–8 个切） | **元素进出型** | 元素的入场/退场，不是剪辑 |
| 硬切很多、镜头 1–2s | **剪辑型**（Vox 拼贴） | 切点位置和每个镜头的构图 |
| 运动强度长期很低、偶有尖峰 | **安静 + 爆点型** | 尖峰处就是招牌时刻，重点切片 |

### 3.2 画面分类
通看联系表，把画面归成几类，每类找 2–3 个代表帧。例：标题卡、年份抬头+引用、对决数字、实物道具、图表、引文、结尾卡。**每一类 = 一个要做的组件。**

### 3.3 固定版式（风格的"框"）
哪些元素在大多数画面都在同一位置？（左上抬头、右上来源、底部字幕、右下水印）→ 做成组件；水印只记位置不抄内容。

### 3.4 细节手法
- **局部放大**：`ffmpeg -ss 31 -i 原片 -frames:v 1 -vf "crop=900:300:0:0" 局部.png` → 衬线/无衬线、粗细、字距、描边、阴影、渐变方向。
- **取色**：底色在四角 + 中心各取一次（判断光晕、暗角）；文字和线条取最亮处。强调色看报告里"有彩像素"统计，不会被大面积背景淹没。
- **质感**：放大平坦区域看颗粒、纸纹、浮尘 → 有就做成叠加层。
- **字体**：先判气质（宋/黑/楷、Garamond/Didot/无衬线），再找许可允许的最接近字体。

### 3.5 动效切片（`scripts/strip.py`）
| 对象 | 切法 | 记录 |
| --- | --- | --- |
| 入场 | 出现前 0.2s 起，窗口 1s，8 帧 | 渐显/模糊/位移/缩放/逐字；几帧完成（例：18 帧，模糊+透明一起收） |
| 退场 | 同上 | 是否与入场对称、是否更快 |
| 转场 | 两画面交界 1.5s | 硬切/交叉淡化/闪白黑场/同元素变形贯穿 |
| 镜头运动 | 长镜头每 2s 一帧 | 是否缓慢推近（例：每场推近 2–3%） |
| 缓动 | 位移动画取 10 帧量位置 | 前快后慢=ease-out；两头慢=ease-in-out；回弹=back/elastic |
| 招牌时刻 | 运动尖峰/重拍附近 `--span 0.6 --n 12` | 收暗→静止→砸 是否存在 |

### 3.6 音频
- 画面节点是否卡在小节线上？高潮是否踩在"换气 + 重拍"上？
- 只报数字（BPM、重拍秒、LUFS）；原配乐不进素材。

### 3.7 多支对照
| 维度 | 视频 A | 视频 B | 视频 C | 结论（特征/变体） |

| 版式 | | | | |

## 5. 自查（做完自己的版本后）
- 同类画面左右拼对比：`ffmpeg -i 原片帧 -i 我的帧 -filter_complex hstack cmp.jpg`。
- 逐项对：底色、主色、强调色、字体气质、字号层级、版式、质感、留白；动效对帧数和缓动。
- 至少两轮。常见问题：小字号渐变字发褐、发光太弱、元素太小留白太多、图表挤在中间。
