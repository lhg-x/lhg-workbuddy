# 学习笔记：WEILANX《Opus 5.5 抖音起号超级保姆级教程》

- 来源：https://x.com/zureA255062/status/2111642497927798995 （2026-10-18）
- 作者战绩：单条 108 万播放 / 2.7 万赞 / 6 万分享；29 条发布，隐藏 19 条，留下 10 条基本过万。
- 作者开源工程：`weilanx-claude-videos`（Remotion + 蒸馏 Skill + 风格素材包，链接在原帖评论区）
- 一句话：**视频只是起号的一小环，账号权重、对标选择、发布后运营同样决定结果。**

## 账号生命周期 9 步

### 1. 准备
- 手机：日常在用、无违规前科；正常注册，不买号不刷机。
- 电脑：Claude 会员(Opus) + Claude Code + Node.js + ffmpeg + uv。

### 2. 账号包装（给系统的第一份标签）
- 定位先泛（"知识分享"），哪个题材爆做哪个；某类反复出数据后再收窄。
- 抄作业：搜 #Vibe知识大赏 → 筛选"最多点赞 + 一周内" → 看爆款号的名字/头像/背景/简介。
- 名字 2–4 字像书名（抽丝剥茧 / 万有引言）；头像简单深奥（宇宙/星空/眼睛）；背景深色安静；简介一句哲思。
- 起名前搜一下避免和大号重名。

### 3. 养号
- 资料设好后**不要马上发**，否则易被判矩阵号。
- 像正常人刷 1–2 小时：停留、点赞、偶尔评论，多刷知识类内容，让系统给你打上兴趣标签。

### 4. 找爆款：只找最新的
- 入口：搜 #Vibe知识大赏 → 话题页 → 选 **最新**（不选最热：老爆款吃的是已验证流量池，新号抢不过）。
- 核心认知：**抖音爆过的东西会一直爆**——选题已被市场验证。
- 目标：发布几小时内、播放已 3000–4000+ 甚至过万。
- 三看：①评论区在吵什么（争论点可放大）②是不是新号/小号（说明爆的是选题本身）③能不能画出来（图表/天平/小世界）。
- 下载：分享→复制链接→解析站下载无水印 → 放 `template/`（不入 git）。

### 5. 复刻制作（最核心）
**第 1 步 蒸馏**：别让 AI 自由发挥。
- 机器拆：镜头表（硬切时间/镜头时长）、每秒运动强度、主色板+强调色（按彩色像素单独算）、关键帧+每 3 秒联系表、配乐响度与卡点。
- 人眼拆：通看联系表给画面分类（标题卡/图表/实物/大字）→ 逐帧放大看字体描边发光 → 入场/转场/招牌动作逐帧数：几帧完成、缓动、模糊缩放。
- 产出：可复用组件 + 预览作品 + 风格配方卡（含"没有搬的东西"）；与原片左右对比自检 ≥2 轮。蒸馏越多条同系列视频，越能分清共性和偶然。

**第 2 步 复刻但更好（田忌赛马）**
- 学：选题、结构节奏（怎么抛问题/几秒一个信息点/哪里爆点）、画面语法、音乐调性。
- 不搬：文案、字幕、标题、水印、原配乐（同质化检测会限流或判搬运）。
- 在三处超过原片：画面冲击力、视觉感染力、**音频卡点（最核心）**。
- 卡点：先测音乐再写画面，时间表从音乐里长出来；2 分钟视频放两个高潮在大重拍上。
  - 重拍前 ~0.75s 画面收暗 → 最后 3 帧静止 → 重拍帧核心词"砸"出 + 冲击音效（一收一停一放）。
  - 小重音"一拍一个动作"。
- 文案：
  - **锚词**：2–4 字、普通人处境而非术语（智猪博弈→"等"）；开头出现、第二高潮砸出、结尾重新定义。
  - 高潮前话说一半（"你猜，最后是谁吃亏了——"）。
  - 结尾抛人人都有答案的问题，大字挂到片尾。

**第 3 步 聊着改**：修改意见 = 位置 + 问题 + 目标 + **边界**（不准动什么）；只渲染单帧确认。

**第 4 步 压成"一锅出" Skill**：给选题 → 查一手资料 → 文案分镜 → 配乐排拍 → 逐帧画面+自检 → 导出 → 3:4 封面 → 标题与描述。
- 一开始就授权到底，只在"查不到一手资料"或"工具连败两次"时停。
- 一手资料：论文读到摘要、书读到原段，数字写进测试核对。
- 自检脚本拼图检查，最多改 3 轮，剩余写进报告。
- 音量有固定标准；AI 听不到声音，最后人耳听一遍。
- 效率：~15 分钟/条；Pro 一天 20+ 条，Max 5x 上百条。

### 6. 发布与诊断
- 封面 3:4，标题与视频内一致；标题 ≤20 字，留悬念不说答案。
- 描述：钩子 → 要点 → 话题（必带 #Vibe知识大赏 + 2–3 个相关）。
- **6 小时看播放**：个位数=权重低（养号/隐藏/发自拍）；几百=多发几条，仍不行就隐藏并发真人实拍；几千=正常，持续发。
- 再看比率：5 秒完播、2 秒跳出、平均播放时长、赞/藏/分享率。
- 作者数据结论：分享率决定推荐量（"被冤枉→翻案"类约为机制类 5 倍）；答案显而易见的标题被跳过；第二人称+痛点；前 17 秒必须交代主题（顶部常驻标题条）。
- 节奏：每天 3–5 条，间隔 3–4 小时，早中晚；周末可多 1–2 条；绝不一天十几条。多做的版本用来挑。

### 7. 运维
- 发到 ~10 条时，隐藏几十/几百播放的，让主页条条爆款：带尾流 + 商务信任。隐藏≠删除，可换标题封面重做再发。

### 8. 投抖加：火上浇油，别雪中送炭
- 1 小时内破万 → 立刻投（作者 30 元目标 1500，实跑 9175，带来 3092 次互动）。
- 6 小时内 3–5 万 → 可试投。
- 慢慢涨卡在一两万 → 不投。

### 9. 废号处理
- 认真对标复刻 5–10 条仍全是几十/几百 → 先按清单自查（对标是否最新、复刻是否完整、节奏是否合规、是否已隐藏和发实拍）→ 注销。
- **注销后停 1–2 天再注册**，否则被风控盯上。每轮素材库和 Skill 都在变厚。

## 写在最后（作者总结）
1. 对标一定要新。 2. 选题/结构/节奏/音乐学全，文案画面自己做。 3. 在爆款基础上锦上添花。 4. 不走没人走过的路。 5. 流程压成 Skill，数据结论写回 Skill。
