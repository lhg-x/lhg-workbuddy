# 评论 & 私域钩子库 v0.1（2026-10-19）

> 起点：小k 第31期口播一句「评论区留言 skill，我把自己用的发给你」，评论 391，评论/赞 5.4%，是小k 样本中位数（2.2%）的 2 倍多。
> 评论数是抖音推荐的重要互动信号，私信 / 粉丝群是之后卖课的池子。下面把"留言 X 我发你"扩成 6 类、30 多个句式，**每期选 1 个主钩子 + 1 个副钩子**，轮着用，别每期一样。

## 0. 三条底线（先看）

1. **视频、字幕、评论里不出现微信号、二维码、手机号、"加V"、谐音**。抖音对站外导流处罚很重（限流 / 删视频 / 封私信）。私域只走站内：私信、粉丝群、主页、橱窗 / 课程
2. **说发就要真发**：用私信自动回复 / 关键词回复（创作者服务中心 → 私信管理，企业号功能更全）兜底，人工回复跟上。只收不发的号，下一期没人留言
3. 钩子要和这一期内容强相关（这期讲设置就送设置清单），越具体越有人留言

## 1. 关键词领资料（小k 原版，主力）

| # | 句式 | 适合 |
| --- | --- | --- |
| 1.1 | 评论区扣「设置」，6 项清单发你 | 清单期 |
| 1.2 | 想要我这套 skill 的，评论区打「skill」 | skill 清单期 |
| 1.3 | 指令原文太长放不下，评论区扣「指令」我私信你 | 提示词期 |
| 1.4 | 扣「1」领模板，扣「2」领录屏原片 | 一次给两种资料，评论翻倍 |
| 1.5 | 留言你的职业，我按职业给你配 3 个 skill | **个性化 → 评论里带信息，还能当选题数据** |
| 1.6 | 评论区扣「手册」，员工手册模板直接给你 | 自定义指令期 |

做法：关键词设成私信自动回复；卡片最后一页用 `cta` 页型（`word` 填关键词）；口播最后 5 秒再念一遍。

## 3. 下期点单（把评论区变成选题池）

| # | 句式 |
| --- | --- |
| 3.1 | 还想让它**自动**做什么？评论区点单，点赞最高的下期拍（小k 结尾原句的升级版） |
| 3.2 | 下期讲 PPT 还是讲表格？评论区投票 |
| 3.3 | 你卡在哪一步了？留言，下期专门讲 |
| 3.4 | 评论区第一个问题，我下期直接录屏回答 |

配合：下期开头说「上期 @某某 问的…」→ 被点名的人会回来，其他人也更愿意留言。

## 4. 留白 / 纠错 / 彩蛋

| # | 句式 | 注意 |
| --- | --- | --- |
| 4.1 | 其实还有第 7 个设置，我放评论区置顶了 | 把一点干货放置顶评论，逼人点开评论区 |
| 4.2 | 视频里有一处我故意说错了，找到的评论区告诉我 | 偶尔用，别真教错东西 |
| 4.3 | 最后一个设置先不说，这条评论过 100 我出下集 | 评论阈值，带系列感 |
| 4.4 | 没听懂的扣「?」，我挨个回 | 门槛最低的评论 |

## 5. 置顶评论模板（每期发完自己先评一条再置顶）

- 「📌 清单 / 模板：评论区扣【设置】自动发你；没收到的看私信"陌生人消息"」
- 「📌 第 7 个设置在这：……（一句话干货）」
- 「📌 下期预告：5 个必装 skill。想看哪个职业版？回复这条」
- 「📌 第 1–6 期合集在主页「WorkBuddy 小技巧」合集里，按顺序看」

## 6. 私域承接（站内闭环）

| 环节 | 做法 |
| --- | --- |
| 私信 | 关键词自动回复发资料；资料末尾一句「更系统的在粉丝群 / 课程里」 |
| 粉丝群 | 开抖音粉丝群（主页可见），群名带"WorkBuddy 交流"；资料、答疑、新课先在群里发，口播可以说「资料在粉丝群」 |
| 合集 | 每 5–10 期建一个合集（新手入门 / skill 清单 / 自动化），置顶评论和主页都指过去 |
| 主页 | 简介写清：日更 WorkBuddy 小技巧 + 资料在粉丝群；置顶 3 条：最爆的清单期 + 系列第 1 期 + 课程介绍 |
| 付费 | 课程走抖音课程 / 橱窗；免费视频结尾一句「这一期是第 N 步，完整流程在课里」（见 `topics-workbuddy.md` §2） |
| 直播 | 粉丝过千后每周一次答疑直播，把评论区的问题集中回答，最后讲课程 |

## 8. 复盘看什么

- 评论 / 赞 比：小k 样本里 11 条视频中位数 2.2%（四分位 1.2%–3.3%），第31期 5.4%。钩子有效的期应该明显高于你自己的均值
- 关键词命中数（私信自动回复次数）÷ 播放量 = 资料转化率，比评论数更接近"私域增量"
- 每周把评论区的问题汇总进 `topics-workbuddy.md`，标注来源期数
