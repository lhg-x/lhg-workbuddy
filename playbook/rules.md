# 规则库（可执行阈值）

> 所有 Skill 和脚本的判断标准以本文件为准。新结论写在"我的数据结论"并注明样本量与日期。
> 初始值来自 WEILANX 教程，未经本账号验证的标记为 `[借鉴]`。

## R1 对标入选
| 项 | 阈值 | 来源 |
| --- | --- | --- |
| 发布时长 | ≤ 24h，最佳 ≤ 6h | [借鉴] |
| 播放量 | ≥ 3000（几小时内）；≥ 10000 优先 | [借鉴] |
| 播放速度 | 播放/小时 ≥ 1000 为强信号 | 推导 |
| 账号粉丝 | < 1 万的小号也爆 → 加分（爆的是选题） | [借鉴] |
| 可画性 | 必须有可视化载体（图表/天平/小世界/对比） | [借鉴] |
| 评论争议 | 评论/点赞 ≥ 5% 或评论区有对立观点 → 加分 | 推导 |
| 分享率 | 分享/点赞 ≥ 1 → 强传播（替自己说话型） | [借鉴] |

## R2 6 小时诊断
| 6h 播放 | 判定 | 动作 |
| --- | --- | --- |
| < 10 | 账号权重低 | 继续养号、隐藏已发、发 1–2 条自拍/生活 |
| 10–999 | 待观察 | 再发 2–3 条；仍卡几百 → 全部隐藏 + 发真人实拍 |
| ≥ 1000 | 账号正常 | 持续发，按节奏 |

## R3 抖加
| 条件 | 动作 |
| --- | --- |
| 1h 内 ≥ 10000 | 立刻投（小额 30 元起，目标互动） |
| 6h 内 ≥ 30000 | 可试投 |
| 其余 | 不投 |

## R4 隐藏
- 账号累计 ≥ 10 条后：播放 < 账号中位数 × 0.1 或 < 1000 的条目建议隐藏（多数万播时）。

## R5 废号
- 连续 5–10 条（均为认真对标复刻）6h 播放全部 < 1000 → 跑自查清单 → 注销 → 冷却 ≥ 48h 再注册。

## R6 发布节奏
- 每天 3–5 条，间隔 3–4h；周末 +1–2；单日上限 6。

## R7 标题/文案
- 标题 ≤ 20 字，留悬念不给答案；优先第二人称 + 痛点（"你为什么老是…"）。
- 前 17 秒（最好第一帧）交代"这期讲的就是你"。
- 选题优先"被冤枉 → 翻案"结构。
- 锚词 2–4 字，三次出现（开头/第二高潮/结尾重定义）。

## R8 卡点
- 重拍前 0.75s 收暗；最后 3 帧静止；重拍帧砸核心词 + 冲击音效。
- 2 分钟片：两个高潮落在大重拍。

## 后台比率参考（作者 AI 口播 vs 知识动画）
- AI 科普口播：5s 完播 12–33%，2s 跳出 50–70%。
- 知识动画爆款：2s 跳出 ≈ 22%。
