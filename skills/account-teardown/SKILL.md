# account-teardown

方法论全文：`playbook/teardown-method.md` §1。调用即授权做到交付，中途不问；只在拿不到主页信息时让用户补截图。

## 输入
- 主页截图（名字/头像/简介区 + 作品网格，最好含每条播放数）或主页链接。
- 可选：Top 3 爆款的详情截图（点赞/评论/分享/收藏/发布时间）。

## 流程
1. **包装**：名字字数与气质、头像主体、背景色调、简介定位 → 列出可抄要素。
2. **作品矩阵**：把可见作品逐条记 `标题 / 播放 / 题材`，计算：
   - 播放中位数、最高、过万占比
   - 题材分布 → 主力题材（出现 ≥3 次且中位数最高的）
   - 系列化（是否有固定系列名/编号）
   - 风格家族数量
   - 更新节奏（如能看到时间）
3. **Top 3 爆款速判**：标题句式、情绪动机、分享率、可画载体。
4. **趋势**：最近 3 天作品是否还在起量 → 判断这个号/题材是上升还是见顶。
5. **结论**：
   - 跟 / 观察 / 不跟（理由一句）
   - 可抄清单：☐包装 ☐主力题材 ☐系列 ☐风格 ☐标题句式
   - 下一步：哪 1–2 条值得进 `benchmark-distill` 拆片
6. 按 `templates/benchmark-account.md` 追加到 `benchmarks/accounts.md`；值得拆的视频追加到 `data/benchmarks.csv`。

## 注意
- 主页"条条过万"可能是隐藏了低播放作品，不要据此高估稳定性。
- 粉丝少但播放高 = 爆的是选题，优先级最高。
