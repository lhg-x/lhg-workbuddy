# trend-radar

## 输入
- 可选：关注领域（默认读 `account/profile.md` 定位）、时间窗（默认 24h）。

## 流程
1. **扫源**（能抓就抓，抓不到就让用户贴截图/链接）：
   - 抖音：搜 `#Vibe知识大赏` → 话题 → **最新**；抖音热榜；创作者中心"热点宝"/"创作灵感"。
   - 外部：微博热搜、知乎热榜、B站热门/科技区、X 上 AI 圈热帖、GitHub Trending（AI 工具类）。
2. **去噪**：剔除纯娱乐八卦、时政敏感、无法核实的内容。
3. **转译成知识选题**：每个热点问"背后是哪个原理/模型/冷知识？"
   - 例：某游戏更新 → "为什么你明明躲进掩体还被打死"（机制 + 被冤枉翻案）。
   - 例：某 AI 产品发布 → "你以为 AI 在思考，其实它在___"。
4. **打三项标**：
   - 热度趋势：上升 / 平台期 / 下降
   - 可画性：0–3（有无图表、天平、对比、小世界）
   - 翻案潜力：0–3（有没有"被冤枉的人"）
5. **找对标**：对每个 ≥ 中等的选题，立刻调用 `benchmark-finder` 找同题已爆视频。没有已爆同题 → 标记"探索型"，降低优先级（规则：不走没人走过的路）。

## 输出：`data/trends/YYYY-MM-DD.md`
```markdown
# 选题简报 YYYY-MM-DD
| # | 热点 | 转译选题（≤20字标题草案） | 锚词 | 趋势 | 可画 | 翻案 | 已有对标 | 优先级 |
|---|---|---|---|---|---|---|---|---|
```
附：Top 3 选题各写一句"开头钩子 + 高潮前半句"。
