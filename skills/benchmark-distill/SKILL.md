# benchmark-distill

授权：调用即授权从拆解做到报告交付，中途不问确认。仅在"视频无法读取"或"脚本连续失败两次"时停下。

## 输入
- `template/` 下的视频文件（1 条或同系列多条，越多越能分清共性 vs 偶然）。
- 可选：对标在 `data/benchmarks.csv` 中的行（带数据）。

## 第 1 步 机器拆
```bash
uv run scripts/analyze_video.py template/<file>.mp4 --out teardowns/<date>-<slug>
```
产出 `analysis.json` + `contact_sheet.jpg` + `keyframes/`：
- 镜头表（硬切时间、镜头时长、平均镜头长）
- 每秒运动强度（找最猛的几秒 = 高潮候选）
- 主色板 + 强调色（彩色像素单独统计）
- 响度（LUFS / 峰值）、BPM 估计、重拍时间点

## 第 2 步 人眼拆（看图）
完整手法见 `playbook/teardown-method.md` §3，按顺序做：
1. **判节奏骨架**：镜头表 + 运动曲线 → 元素进出型 / 剪辑型 / 安静+爆点型，决定重点学"入场退场"还是"切点构图"。
2. **画面分类**：通看 `contact_sheet.jpg`，归成几类，每类 2–3 个代表帧；每一类 = 一个组件。
3. **固定版式**：找每帧都在同一位置的元素（抬头、来源、字幕条、水印位）。
4. **细节**：`ffmpeg -vf crop=…` 局部放大看字体/描边/阴影/渐变；四角+中心取底色，最亮处取文字色；看有无颗粒/纸纹。
5. **动效切片**：`uv run scripts/strip.py <视频> --at <秒> --span 1 --n 8 --out teardowns/<slug>/strips/t<秒>.jpg`
   - 入场：出现前 0.2s 起、1s、8 帧，数几帧完成；退场同法；转场在交界切 1.5s
   - 长镜头每 2s 一帧看推近；位移取 10 帧判缓动（ease-out / in-out / back）
   - 招牌时刻（运动尖峰、重拍附近）：`--span 0.6 --n 12`
6. **对齐卡点**：运动峰值 × 硬切 × 重拍对表，标"画面跟拍"处与高潮；检查"收暗 → 静止 → 砸"。
7. **多支视频**：填 §3.7 对照表，一致的进特征，不一致的记变体。

> 每条观察都写数字（色值、帧数、秒、百分比）。

## 第 3 步 内容结构拆
- 逐段转写（可用 whisper 或让用户提供字幕），只用于分析，**不复制进作品**。
- 拆：开头钩子（前 3 秒说了什么）、问题抛出时间、信息点密度（几秒一个）、高潮位置、锚词、结尾提问。
- 评论区：主要争论点是什么 → 是否能在我的版本里放大。

## 第 4 步 写报告
用 `templates/teardown-report.md`，写到 `teardowns/<date>-<slug>/report.md`，必须包含：
- 风格配方卡（配色/字体/版式/转场/节奏/招牌画面）
- **没有搬的东西**（原文案、字幕、配乐、水印、人名）
- **超越点**：画面冲击力 / 视觉感染力 / 卡点 各给 1–3 条具体改法
- 适配我的生产线：映射到火柴人（stickman-director）或手绘费曼（feynman-teach）的哪些组件/风格

## 第 5 步 自检
- 报告里的每个时间点能在 `analysis.json` 里找到依据。
- 音频只报数字，提醒用户戴耳机确认调性。
