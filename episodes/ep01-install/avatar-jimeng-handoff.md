# 交接：在即梦里做「照片数字人」圆框样片（给 Muse）

目标：用用户的**一张照片 + 一段音频**，在即梦（jimeng.jianying.com）生成会说话的头像视频，用作成片左下角圆形出镜窗。参考效果：leviiii2026（见 `teardowns/2026-10-19-leviiii2026/avatar-audio-recheck.md`）——背景静止、头自然转动/点头、会眨眼、嘴型对上声音。

> 本轮只做**样片跑通**，不批量。登录、付费/积分购买、授权声明 → 停下来交给用户。

## 1. 照片（用户按上传顺序编号 1–17，向用户索取原图）
| 优先级 | 编号 | 描述 | 备注 |
| --- | --- | --- | --- |
| **主选** | **#16** | 青绿色窗帘背景、黑毛衣、条纹衣领、正脸 | 第一个测 |
| 备选 | #8 | 家里、蓝色窗帘背景 | 对比用 |
| 备选 | #10 | 正脸干净 | 背景杂，必要时先抠图换纯色背景 |
| 不用 | 13/12/17、7/14、15、2/5/11、3/9 | 帽檐阴影/仰拍、模糊、太近、水印（#11 有小红书水印） | — |

照片要求：正脸、脸部无遮挡、头顶和肩膀都在画面内（后期要裁成圆形，脸要居中）。

## 2. 音频（两组对比，各约 15 秒）
测试文案（约 15 秒）：
> 大家好，我是 lhg·AI实验室。这个系列，我会从零开始，带你把 WorkBuddy 真正用起来。今天第一期，先用三分钟，把它装好。

- **A 组：真人录音**——用户用手机在安静环境录上面这段（m4a/wav 均可），可在剪映里做「智能去气口」后再用。
- **B 组：即梦/剪映克隆音色**——若即梦数字人支持上传声音样本克隆或选择克隆音色，用用户声音克隆后朗读同一文案；不支持就用平台自带最接近的男声，并记录音色名称。

## 3. 操作步骤（以即梦页面实际为准）
1. 打开即梦 → 进入「数字人 / 对口型」功能（OmniHuman 能力）。用户需已登录；未登录则停下。
2. 上传照片 #16。
3. 上传音频（A 组）；生成。
4. 同一照片 + B 组音频再生成一条。
5. 若积分允许：#8 + A 组音频生成一条做形象对比。
6. 下载 mp4，**不要加平台水印以外的任何处理**。
7. 每条记录：功能入口名称、模式/参数、消耗积分、生成耗时。

## 4. 交付
- 存到 `~/Movies/wb/ep01/avatar/`：`a16_real.mp4`、`b16_clone.mp4`、（可选）`a08_real.mp4`，以及原始音频 `a_real.m4a`。
- 写一份 `notes.md`：上面第 3.7 条记录 + 主观评价（按下表打 1–5 分）。

| 检查项 | 说明 |
| --- | --- |
| 口型同步 | 嘴型与声音是否对齐，有无延迟 |
| 头部动作 | 是否自然（转头/点头），有无抽搐、漂移 |
| 脸部稳定 | 五官、眼镜、发型有无变形闪烁 |
| 背景 | 是否稳定、无扭曲 |
| 构图 | 裁成圆形后脸是否居中、头顶不被切 |
| 声音 | B 组像不像本人；有无错读、吞字、机械感 |

## 5. 注意
- 只用用户本人的照片和声音；发布抖音时勾选「AI 生成内容」声明（成片阶段处理）。
- 遇到登录、付费、隐私授权弹窗 → 停，交给用户。
- 成片合成（圆框裁切、卡片、字幕、BGM）由 Claude 后续用 `scripts/render_canvas.py` 处理，Muse 只负责交付原始数字人视频。
