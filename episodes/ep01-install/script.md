# 第1课 口播稿：3 分钟装好 WorkBuddy，让 AI 替你写完第一份周报（真人录制版，目标 70–90s）

> 系列：**把 AI 养成你的员工 · 第 N 课**（每期开头 = 第 N 课 + 学完能做到什么 + 能带走什么）
> 功能依据：腾讯云开发者社区《workbuddy新手小白快速入门（一）》、WorkBuddy 官方文档。标 ⚠️ 的入口录前在自己电脑上核对。

**录前准备**
- 桌面建文件夹「练习-周报」，放：`本周工作记录.txt`（下方样例）+ 1 张随便的数据截图或 Excel。
- WorkBuddy 已装好的话先退出；安装段落可用旧录屏或重装录一遍，后期 2–3 倍速。
- 登录二维码、手机号后期打码。

## 提词器版（口语化，短句，一行一口气）

> 指令全文**不念**，屏幕上展示；口播只说一句大意。网址不念、不放链接，只说「搜名字进官方网站」。

> 双平台（抖音 + 视频号）版：不提其他平台名、不念网址、不导流站外、不用绝对化和承诺类说法。

**【开头｜先放成品周报】**
这份周报，不是我写的。
是 AI 读完我这周的工作记录，自己写出来的。
今天第一课，三分钟，教你也用上这样的 AI 助手。
用到的指令，我放在评论区。

**【是什么｜真人 / 界面】**
它叫 WorkBuddy，腾讯出的。
跟平时聊天的 AI 不太一样，
它不只是回答问题，还能在电脑上把活干完。

**【安装｜加速】**
安装很简单，搜它的名字，进官方网站下载。
装好打开，用手机扫码，就能登录。

**【界面｜光标划过左中右】**
界面就三块：
左边是任务，中间跟它说话，右边看结果。

**【开干｜新建任务 → 选文件夹 ⚠️】**
我们直接让它干活。
点「新建任务」，选上我放资料的这个文件夹。
它只会处理这个文件夹，别的地方不会碰。

**【指令｜粘贴指令，屏幕展示全文】**
然后跟它说，就像跟同事交代工作一样：
帮我把这周的工作记录，整理成一份周报。

**【干活｜加速】**
发出去，它就开始读文件、写周报了。
每一步在干嘛，你都看得到。

**【验收｜打开周报滚动】**
好了，打开看看。
做了什么、数据、问题、下周计划，全排好了。
自己再改两句，就能用了。

**【套路｜字幕卡：材料 / 要求 / 放哪】**
所以就记一句话：
告诉它材料在哪、要什么、放哪儿，它就能替你干。

**【结尾｜真人】**
下一课，一句话，把乱成一团的文件夹整理干净。
每节课，让 AI 多帮你做一件事。我们下节课见。

**演示指令（评论区置顶同款）**
> 读取这个文件夹里的「本周工作记录.txt」和其他资料，帮我写一份周报，保存成 Word。结构：本周完成（分条，带数据）、遇到的问题、下周计划。语气正式简洁，一页以内。记录里没有的数据不要编，写「待补充」。

**样例 `本周工作记录.txt`**（可换成自己的真实内容）
```
周一：和设计对齐新版落地页，确定首屏文案
周二：上线落地页 A/B 测试，B 版转化率 3.2%，A 版 2.1%
周三：整理用户反馈 48 条，主要集中在注册流程太长
周四：和研发评审注册流程优化方案，预计下周开发
周五：写月度复盘初稿，还差渠道数据
```
