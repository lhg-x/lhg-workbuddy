# 第1期 口播稿：3 分钟装好 WorkBuddy（真人录制版，目标 60–80s）

> 功能依据：腾讯云开发者社区《workbuddy新手小白快速入门（一）》、WorkBuddy 官方文档。录前请在自己的 WorkBuddy 上核对标 ⚠️ 的入口名称/位置（版本不同可能有差异）。

| # | 口播 | 画面 / 操作 |
|---|---|---|
| 1 钩子 | 还在跟 AI 一问一答？今天教你装一个能直接动手帮你干活的 AI 同事——腾讯的 WorkBuddy。 | 真人出镜，或 WorkBuddy 正在自动生成文件的画面 |
| 2 官网 | 第一步，只认官方入口：codebuddy.cn/work。网上有不少山寨下载站，别乱点。 | 浏览器输入 `codebuddy.cn/work` → 选 WorkBuddy |
| 3 下载 | 点「下载 WorkBuddy」，网站会自动识别你的电脑：Mac 分苹果芯片和英特尔，Windows 选 x64。 | 点击「下载 WorkBuddy」 |
| 4 安装 | Mac 打开安装包，把 WorkBuddy 拖进「应用程序」；Windows 双击，按向导下一步就行。 | 拖拽图标到「应用程序」 |
| 5 登录 | 打开后点登录，会跳到网页，微信扫码或者手机号都可以。 | 点登录 → 网页 → 扫码（二维码打码） |
| 6 界面 | 界面记住三块就够了：左边侧边栏，新建和切换任务；中间对话区，用大白话说需求；右边结果区，看它做出来的文件。 | 光标依次划过左 / 中 / 右 |
| 7 模式 | 输入框这里有三种模式：问一问，只聊天不动文件；做一做，直接动手；想一想，先出计划，你点头才执行。新手先用「想一想」最稳。 | 点开模式切换 ⚠️（Ask/Craft/Plan） |
| 8 更新 | 以后有新版本，点左下角个人中心，「检查更新」就行。 | 左下角个人中心 → 检查更新 ⚠️ |
| 9 结尾 | 装好了评论区扣个 1。下期带你用它做第一件事：一句话，把乱成一团的文件夹整理干净。关注我，从小白带你到进阶。 | 真人出镜 / 输入框静止 |

录前准备：WorkBuddy 先退出；浏览器只留一个标签；登录二维码、手机号后期打码。
