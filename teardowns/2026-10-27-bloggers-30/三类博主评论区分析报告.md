# 三类博主评论区分析报告：WorkBuddy 垂类 × Codex 垂类 × 头部 AI 讲课

- 抓取日期：2026-10-27
- 数据面：抖音免登录搜索接口（so.douyin.com，爬虫 UA）+ web 评论接口（一级评论，爬虫 UA），全程匿名、无登录态，请求间隔 ≥1.6 秒，全程零抓取失败
- 工具：lhg-social-get v1.1.0（search.py / douyin_comments.py）
- 产出数据：`videos_over500.json`（112 条入选视频元数据）、`comments_bloggers.jsonl`（52,206 条去重评论，带博主与类别标记）

## 样本与局限（先读）

1. **选人是数据驱动的，不是点名**：三类候选分别由关键词搜索聚合 + 已有 WorkBuddy 视频池（212 条）按作者聚合产生，再按各类口径筛选（见各表表注），粉丝量用 `user/profile/other` 接口逐个核验。
2. **视频样本来自搜索索引，不是主页全量**：抖音主页作品接口被 Argus 拦截，免登录无解。每位博主的视频 = 关键词搜索命中 + 以其昵称为关键词的定向搜索命中，两路合并去重；只收录点赞 >500 的，每人最多取点赞最高的 15 条。搜索索引偏新、偏热门，老作品与冷门作品覆盖不全，**「入选视频数」是下限，不是该博主 >500 赞视频的总数**。
3. **评论口径**：只抓一级评论（不含楼中楼），单视频最多翻 60 页；元数据 `comment_count` 含楼中楼与不可见评论，实抓一级评论少于元数据属正常。单条热度 = 点赞 + 5×回复数（沿用本工作区既有口径）。
4. **存量复用**：WorkBuddy 池视频与「小k的AI日记」专项的评论直接复用此前抓取的存量（wb-pool 43,011 条 + 小k专项 1,284 条），按 cid 去重合并，本次新抓 47,073 条。
5. **粉丝量是取整值**：profile 接口返回的粉丝数为取整结果（如 100 万档多人并列），只作量级参考；AI 类并列时用搜索快照粉丝数细排，表中标注。
6. **话题/痛点为关键词编码 + 高热原话人工校验**：短评、表情、打卡类评论占比高（尤其 WorkBuddy 类），关键词痛点计数会低估真实痛点密度，报告中以高热原话佐证；评论含观众昵称，对外引用需脱敏。
7. **落选说明（AI 类）**：艾斯AI💫（快照粉丝约 269 万）、AI课代表小明（约 218 万）、盖世人工智能讲堂（约 196 万）、阿祖搞AI（约 163 万）粉丝量本可入围，但按其账号定向搜索后，搜索索引内**找不到任何一条点赞 >500 的本人视频**（小明最高一条仅 266 赞），无可分析样本，按口径落选并在此留名；影视飓风（约 1,700 万）、姜Dora在此（约 402 万）因主业分别为影视科技媒体、职场成长，AI 课只是其内容支线，不符合「以 AI 教学为主」，未入选。

## 五、横向对比

### 5.1 选题打法差异

| 维度 | WorkBuddy 垂类 | Codex 垂类 | 头部 AI 讲课 |
|---|---|---|---|
| 主力形态 | 单点技巧日更系列（小k「每天一个小技巧」43 期）+ 保姆级长教程立号 | 「速通合集 / 一期精通」型长教程三部曲（林粒粒呀、技术爬爬虾） | 「40 分钟学会 X」体系课 + 大众工具场景课（秋芝2046） |
| 核心钩子 | 积分与省钱（自动领积分、8 项设置）、现成 Skill 包、配套文档（蓝皮书） | **破壁**：国内网络跑通、免 OpenAI 账号、接入国产模型、改中文 | 职场痛点（表格、PPT、工资梗）+「零基础终级教程」的话术势能 |
| 差异化来源 | 谁的技巧更细、文档更全 | 谁能把人真正带进门（跨界场景如 Codex×CAD 是新爆点） | 品牌矩阵与课程体系（秋叶）、人格化 IP |
| 爆款结构 | 一条长教程吃全号（晓墨单条占全类评论 26%） | 合集型爆款 + 跨界单条（Kid学长 CAD 条 6,815 评） | 超级单条（秋芝 Codex 教程 59 万赞）+ 系列矩阵 |

一个值得注意的交汇：**头部讲课号点赞最高的单条讲的是 Codex（秋芝 59 万赞），头部号怼怼教AI 的爆款讲的是 WorkBuddy 领积分，卡卡大王的代表作是 Codex 纳米级教程**——垂类话题正在被头部号「收割式覆盖」，垂类号的生存空间在更细的技巧、更新的速度和更近的答疑。

### 5.2 评论区生态差异（构成占比，按关键词规则分类）

| 构成 | WorkBuddy（10,929 条） | Codex（14,239 条） | 头部 AI 讲课（27,038 条） |
|---|---|---|---|
| 提问答疑 | 3% | **24%** | 14% |
| 求资源 | 8% | 6% | **19%** |
| 夸赞认同 | 8% | 3% | 7% |
| 争议质疑 | 0.2% | 1% | 0.7% |
| 其他（短评/表情/打卡/闲聊） | 80% | 66% | 59% |

- **WorkBuddy 评论区 = 领取处 + 打卡区**：实质讨论密度三类最低，长尾全是领文档、领积分、晒签到的留言；但一旦有人提问，问题高度集中（见 5.3）。氛围最温和，争议几乎为零，夸赞占比三类最高——国产工具、无墙、免费入门，观众情绪成本低。
- **Codex 评论区 = 技术支持论坛**：近四分之一是正经提问，同行互助显著（全场最高热评论就是观众给的技术答案，热度 10,553），争议也最高（路线之争、值不值、国产替代的情绪）。博主答疑缺位时，观众自己把论坛办起来了。
- **头部讲课评论区 = 巨型资源领取处 + 情绪共鸣场**：求资源占比三类最高（秋芝一号就占 28%），「老师」式称呼、课后答疑、职场情绪宣泄（工资、加班、被时代抛下）各占一摊；人均讨论深度最浅，但总量与情绪浓度最高。

### 5.3 观众痛点差异（核心问答：Codex 观众 vs WorkBuddy 观众）

**结论先行：Codex 观众卡在「门外」，WorkBuddy 观众卡在「钱包和产出」。**

| 痛点（关键词编码条数/代表原话） | Codex 观众 | WorkBuddy 观众 |
|---|---|---|
| 网络/账号门槛 | **448 条，全场最痛**：「codex注册不了了……需要国外电话号码」「90%的人停在搞不定账号上」 | 近乎为零（国产、无墙） |
| 装不上/打不开 | 384 条：「为什么下载后打不开」「更新后软件崩了」 | 少量（登录不了、软件卡） |
| 界面语言 | 反复出现：英文界面、找不到中文选项（CX 特有） | 无 |
| 收费/积分焦虑 | 168 条，形态是 Plus 会员与境外支付渠道（「哪些卡可以买」） | **签名痛点**：「workbuddy里边要钱吗」（单条最高热）、「先充钱，没钱啥也不会干」、「领10个积分，需要消耗100积分」、「核心问题，收费挺高」 |
| 慢/完不成 | 261 条，多为卡住、子线程异常 | 「各种慢吞吞，十几、几十分钟之后发现任务完不成」（全类最高热痛点，赞 503） |
| 产出质量 | 做 PPT 垃圾、AI 味台词 | **胡说八道**是专门选题（「五句话让workbuddy再也不敢胡说八道」6,956 赞）、总结完就忘 |
| 安全/涉密 | 稀少 | 办公场景特有：「这个会涉密吗」出现在多个号下 |
| 选型纠结 | 与 Claude Code 的路线之争（技术性） | 「workbuddy 和扣子哪个更好」（工具货架前的新手） |

展开说：
- **Codex 的痛点是前置的、准入型的**：梯子、国外手机号验证、OpenAI 账号、境外支付、英文界面、下载打不开——每一步都有人成批掉队（知雪评论区原话：「90%的人停在搞不定账号上」）。更扎心的是供给侧的结构性沉默：老张评论区「全抖音就没有一个人讲第一步网络环境怎么操作的」——博主们默契地跳过最痛的一步（非哥自述这类内容「不让发」），导致**「破壁教程」成为 CX 类最稀缺也最爆的内容**（爬爬虾《从零开始用国内网络，跑通一切AI Agent工具》51,657 赞、马克《无需OpenAI账号》59,067 赞都是明证）。
- **WorkBuddy 的痛点是后置的、消耗型的**：门不用破（国产、微信/QQ 生态、免费下载），用起来之后开始疼——积分消耗看不懂（自动任务烧积分、领 10 耗 100）、会员值不值、跑得慢、任务完不成、回答胡说八道、公司数据涉不涉密。观众的怒气不在「进不去」，在「进去了发现养不起、靠不住」。
- 因此两类内容的「解题方向」完全不同：CX 要补的是**准入基础设施**（网络、账号、支付、语言、安装），WB 要补的是**成本与可靠性教育**（积分账本、省积分设置、防胡说指令、运行条件说明）。

### 5.4 头部 AI 讲课 vs 垂类博主：评论区有什么不同

1. **需求颗粒度不同**：头部观众的问题是「有没有现成的」（求资源 19%、求课件、求资料包）；垂类观众的问题是「我这一步怎么办」（CX 提问答疑 24%，且大量带具体报错与环境信息）。头部卖的是确定性，垂类卖的是解题。
2. **焦虑类型不同**：头部的签名焦虑是**时代焦虑**（「高考生看这个好崩溃」「以后不熟悉AI的人会不会越来越跟不上」）；垂类的签名焦虑是**任务焦虑**（装不上、积分不够、任务完不成）。前者驱动收藏与转发，后者驱动提问与互助。
3. **博主角色不同**：头部是「老师」——评论区有尊称、有课后答疑、有付费意愿（「唯一想付费学习的博主，结果没有入口」）；垂类是「同行/班长」——观众在评论区互相递答案、接龙助人（「努力让100个人用上codex」），博主缺席答疑的成本更低。
4. **商业气味的耐受度不同**：头部样本中混着带货与品牌合作（AI 眼镜、汽车合作、短剧引流），评论区照单全收；垂类观众对「收费」二字的敏感度反而更高（WB 的积分、CX 的会员），因为他们是真的要掏钱用工具的人。
5. **数据结构不同**：头部是超级单条驱动（秋芝一号 = 本类 67% 评论；秋叶 Excel 靠职场短剧钩子），垂类是腰部均匀分布（CX 类 10 人评论量在 190–3,263 之间，没有一号独大）。

### 5.5 给做号的三条可执行结论

1. **做 WorkBuddy 内容**：先回答钱的问题——每条视频默认交代清积分消耗与免费边界；把「防胡说设置、省积分设置、运行条件（关机行不行）」做成固定栏目；评论区认真答疑就是差异化（头部博主在评论区几乎不答疑，见此前 wb-pool 调研：2,915 条楼中楼里博主本人回复仅 21 条）。
2. **做 Codex 内容**：最大的流量洼地是「第一步」——网络、注册验证、支付、中文界面的完整破壁链，谁能合规地讲透谁吃肉；其次是跨界场景（Codex × CAD/办公/设计），Kid学长的评论区证明场景共创的传播力大于纯教程。
3. **对标头部讲课号**：学的是结构不是体量——「长教程 + 大众工具 + 职场场景 + 资源钩子」四件套（秋芝模式），以及把评论区的求资源流量用文档/清单承接住（小羊-workbuddy 的蓝皮书打法在垂类同样有效）。
