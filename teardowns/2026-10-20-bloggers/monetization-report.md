*注：一个博主可有多种变现，总和 >100。*

### 头部（>50万粉，28 个）vs 腰部变现差异
- 头部 28 个中：广告 18 个（64%）、私域 11 个、私域+广告组合最常见
- 卖课在头部只有 3 个（秋叶AIPPT、老达等），**头部反而少直接卖课**——他们卖的是"影响力"（广告）和"信任"（私域沉淀后再转化）
- 腰部（10-50万粉）是卖课/咨询的主力：粉丝不够接大商单，转做高客单价服务

## 四、引流路径拆解（3 条完整路径）

### 路径 A：秋叶系（矩阵+私域+企业培训）
```
抖音视频（干货教程）→ 主页 bio 微信 → 企微私域 → 免费体验课 → 企业定制培训（高客单）
```
- 特点：不急于变现，先做大规模信任；企业客户客单价高，一单顶一万个 C 端用户

### 路径 B：赵焱（官方背书+B2B）
```
抖音视频（企业提效 skill 免费分享）→ bio 官方代理商身份 → 微信 → 企业 FDE 部署/定制 agent
```
- 特点：用"官方授权"做信任状；免费 skill 引流，B 端部署变现；WorkBuddy 生态内独有

### 路径 C：腰部卖课（内容+私域+训练营）
```
抖音视频（痛点教程）→ 评论区"想要的打1"→ 私信发微信 → 朋友圈种草 → 训练营/陪跑（199-999）
```
- 特点：评论区做钩子，私信做承接，朋友圈做转化；全链路在 3 天内完成

## 五、给"把 AI 养成你的员工"的建议

### 最适合的 2 种模式

**1. 卖课（训练营制）——主模式**
- **为什么**：你的免费内容（100 条小技巧+6 课）已经是完整的"种草机"；用户画像（想学 WorkBuddy 的职场人/小白）付费意愿明确；赛道验证过（秋叶、老达都在跑）
- **定价**：199 元首发（对标赵焱 199 智能体，用户心理锚点已存在），后续 299
- **产品**：不是"更多小技巧"，而是"体系+陪伴+作业"——M1 自制 Skill/M2 工作流/M3 场景/M4 变现（大纲已在 playbook/paid-course-outline.md）
- **差异化**：别人的课教"通用 AI"，你的课教"WorkBuddy+中文 skill+蓝皮书"——生态绑定，别人抄不走

**2. 私域沉淀（企微）——基础设施**
- **为什么**：100 个博主里 20 个做私域，头部 64% 接广告的前提是有私域；定价藏私域是铁律，你不做私域等于把定价权让出去
- **怎么用**：不卖货，先做"资料钩子"——每条视频评论区"想要 skill 清单的打1"，私信发微信，企微自动发《8 个 skill 清单 PDF》+ 训练营早鸟价
- **冷启动**：前 1000 粉丝全部沉淀到企微，这是你最值钱的资产

### 不建议现在做的
- **广告/商单**：粉丝 <50 万接不到好单价，且会伤害"教程"人设的纯粹性
- **B2B 代运营**：赵焱的路很好但需要官方授权+交付团队，你现在是单人，先跑 C 端
- **带货**：与"教程"定位冲突，除非带 WorkBuddy 周边（暂无）

### 冷启动 30 天步骤
1. **Day 1-7**：企微建好，自动回复配好《8 个 skill 清单》；每条视频评论区置顶"清单打1"
2. **Day 8-14**：发 5 条常青款视频（首拍 30 的前 5），测试哪条私域转化率最高
3. **Day 15-21**：根据数据定训练营主题（M1-M4 哪个呼声最高），写招生文案
4. **Day 22-30**：199 元早鸟价开营，目标 50 人（=1 万元，验证模型）；全程在企微交付

### 一句话总结
**别学头部接广告（那是 100 万粉之后的事），学腰部的"内容→私域→训练营"；别碰 B2B（那是团队的事），把 C 端 199 元训练营跑通。你的 100 条免费内容就是招生简章，每一条都在为训练营投票。**
