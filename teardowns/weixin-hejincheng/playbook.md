## 二、钩子四件套（0-15 秒）

1. **禁止式指令**："WorkBuddy下载完，千万别直接用"——点名产品 + 禁止动作，制造焦虑缺口
2. **生活化比喻**："就像招了个员工，却没告诉他你是谁、该怎么干活"——把"初始化配置"翻译成带新人的场景，0 理解成本
3. **时间承诺**："花 2 分钟改完这几个地方"——明确投入，低门槛
4. **三级收益**："他就会记住你的工作（记忆）→ 按你的规矩办事（指令）→ 甚至你不在电脑旁也能用手机让他干活（远程）"——层层递进，最后一个最性感

## 三、正文：8 个设置的"位置+动作+收益"三件套

每个设置都是：**在哪点 → 点什么 → 不做会怎样/做了有什么好**。顺序经过设计：

1. **存储**：工作区 C 盘→D 盘。"后面的文件越积越多，很容易把 C 盘塞满"——**痛点前置**。"Mac 用户这一步直接跳过"——分用户给指令，不浪费任何人时间
2. **技能自动更新**：打开。"以后装过的技能都会自动更新，不用自己盯着"——收益=省心
3. **智能体设置→本地技能与记忆沉淀**：打开。"用过的技能和使用习惯慢慢沉淀下来"——收益=越用越顺
4. **记忆→对话记忆**：打开。"聊天中提到的新工作新项目，他会自动记住"——呼应钩子收益①
5. **自定义指令**（全片重心，篇幅最长）：
   - 先讲真痛点："很多人卡住的不是找不到入口，而是根本不知道这里该填什么"
   - 给解法：自制"初始化"话题/skill，采访式一问一答+参考答案，答完自动生成指令
   - 给示例："回答前先给结论""删文件前先问你一嘴""做完主动检查"
   - 呼应钩子收益②
6. **基本风格语调**：按习惯选，专业严谨 / 毒舌吐槽——给选择权，"毒舌"一词自带趣味
7. **模型**：内置够用 + 可配自己 API——先降门槛，再留扩展口
8. **助理设置**：绑微信/企微/QQ/飞书 + 锁屏远程打开——"人不在电脑旁也能用手机指挥"，呼应钩子收益③

**结构心机**：
- 开头承诺的三个收益，在正文第 4/5/8 步**逐一兑现**——首尾呼应，观众有"说到做到"感
- 8 个点里只有第 5 步是重心（自制工具引流），其余 7 个是配菜——**重心设计**，不平均用力
- 全程一镜到底录屏，无废话

## 五、可复用的 7 个公式

1. **禁止式钩子**：[产品]下载完，千万别[直接做某事]——比"教你XX"停留感强
2. **员工比喻**：一切 AI 配置问题都翻译成"带新人"——用户秒懂
3. **2 分钟承诺**：明确时间投入，观众才敢点进来
4. **痛点前置**：每个设置先说"不做会怎样"，再说怎么做
5. **首尾呼应**：开头承诺 N 个收益，正文用 N 个步骤逐一兑现
6. **重心设计**：一期只推 1 个重点（自制工具/引流点），其余做配菜
7. **系列化结尾**：固定句式 + 期数，"下期再见"培养追更
