# WorkBuddy 赛道标题标签打法手册

> 数据源：抖音 100 条 WorkBuddy 爆款（2026-10-20，按收藏+点赞排序）
> 配套：topics.json（原始数据）、topics.md（逐条拆解）

## 一、标题公式（按出现频次排序）

### 公式 1：保姆级/小白（18 条，Top20 占 7 条）
**句式**：WorkBuddy + 保姆级/零基础/小白 + 教程/实战课
- #1 [张瑞麟AI] workbuddy 零基础保姆级实战课，小白也能学会（5.5万赞）
- #2 [小羊-workbuddy] WorkBuddy保姆级教程 零基础入门（3.2万赞）
- #9 [AIGC-玥] 超详细的WorkBuddy Skill 保姆级教程来了
**数据**：Top20 里 35% 用此公式，是头部的最爱。核心词"保姆级"出现 18 次、"零基础"12 次。
**适用**：新手向、长视频、系列开篇。

### 公式 2：数字+清单（17 条，Top20 占 6 条）
**句式**：[动作] + 数字 + 个/大/种 + Skill/设置/技巧
- #3 [何公子] 装完Workbuddy，先装这10个Skill技能（1.8万赞）
- #12 [西米鹿] WorkBuddy必装10大skill
- #8 [小k] 让你拥有下载量最高的8个skill（1万赞）
**数据**：Top20 里 30% 用此公式。数字以 5/8/10 最常见。
**适用**：skill 合集、设置合集，清单体永不过时。

### 公式 3：自动X（13 条）
**句式**：让 WorkBuddy + 自动 + 动词
- #4 [小k] 让你学会自动领积分（2.1万赞，全场最高）
- #7 [怼怼教AI] 让WorkBuddy自动领取积分（1万赞）
- #11 [成也2077] 教会你的WorkBuddy
**数据**："自动"出现 13 次；"自动领积分"一题 5 人做（#4/#7/#19/#32/#67），是验证过的常青款。
**适用**：任何能自动化的场景，标题里有"自动"点击率直接上一个档。

### 公式 4：禁止式（5 条）
**句式**：WorkBuddy + 装完/下载完 + 别直接用/先不要用
- #24 [码上AI] WorkBuddy装完别直接用（1924赞）
- #42 [占占超Nice] workbuddy 下载完先不要用
- #74 [木子的AI工位] WorkBuddy别直接用
**数据**：何锦成视频号原版"WorkBuddy下载完，千万别直接用"拿 6.4 万转发；抖音仿写版 #24 拿 1924 赞，证明公式可迁移。
**适用**：设置类、初始化类视频，开头 3 秒留人最强。

### 公式 5：结果前置（5 条）
**句式**：让你学会/让你拥有/教你 + 具体好处
- #4 [小k] 让你学会自动领积分
- #8 [小k] 让你拥有下载量最高的8个skill
- #17 [宇阳说] 教你 24 小时用 Ai 赚到钱
**数据**：小k 两条爆款都用"让你__"，是他的标志性句式。
**适用**：小技巧系列，每期一个具体可交付的结果。

### 公式 6：系列化（小k 专属，6 条上榜）
**句式**：每天一个workbuddy小技巧，第X期，+ 结果
- #4 第九期让你学会自动领积分（2.1万赞）
- #8 第十二期让你拥有下载量最高的8个skill（1万赞）
- #50 第二十七期让你学会用workbuddy操控网页
**数据**：小k 6 条上榜，平均 5753 赞；"第X期"给观众追更预期，合集页天然流量池。
**适用**：日更系列，直接抄。

### 公式 7：提问式（4 条）
**句式**：如何/怎么 + 用workbuddy + 做某事
- #22 [怼怼办公技巧] 如何用workbuddy做数据可视化
- #64 [独立工作者] 如何在workbuddy中使用skill技能
- #98 [顺哥AI搭子] Work buddy 装完必须改的五个设置，你设置好了吗
**适用**：搜索流量，标题即问题，精准捕获。

### 公式 8：效果承诺（4 条）
**句式**：[动作] + 让老板/让你的 + 离不开/越用越__
- #10 [黄ccc] 手握workbuddy全技能，让老板根本离不开你
- #86 [Haco不闲着] 这两个设置让WorkBuddy越用越懂你
- #48 [卡皮码] 跟着学让你的workbuddy越用越上手
**适用**：职场人群，"离不开""越用越"直击打工人痛点。

### 公式 9：必X式
**句式**：WorkBuddy + 必装/必改/必须 + 数字 + 设置/skill
- #12 [西米鹿] WorkBuddy必装10大skill
- #87 [小huang说] workbuddy必改的5个设置
**适用**：清单体的变体，"必"字制造紧迫感。

### 公式 10：白嫖利益
**句式**：免费/自动领/薅 + 具体好处
- 本质是公式 3 的子集，但动机不同：不是"自动化省事"，而是"不花钱得好处"
- #4 自动领积分（省积分钱）、#19 一键解锁（省钱）
**适用**：积分、会员、免费模型相关选题。

## 三、标签策略

### 覆盖率（100 条）
| 标签 | 覆盖率 |
|------|--------|
| #workbuddy | **88%（必带）** |
| #ai | 36% |
| #ai办公 | 22% |
| #agent | 18% |
| #ai工具 | 17% |
| #ai智能体 | 16% |

### 组合规律
- **平均 4.2 个标签**，5 个标签最主流（62 条）
- 标准组合：`#workbuddy` + `#ai` + 1 个垂类（#ai办公/#ai工具/#ai智能体）+ 1 个场景（#效率工具/#职场干货/#自媒体）+ 1 个内容属性（#零基础/#干货分享/#保姆级教程）
- **标签数与数据无强相关**：0 标签的 5 条平均赞 4855 反而最高——内容 > 标签，标签只做基础覆盖
- 小k 固定组合：#workbuddy #干货分享 #skill #知识分享（6 条全用这套）

### 标签分层（照抄用）
1. **必带**：#workbuddy
2. **流量**：#ai（三选一或全带：#ai #ai工具 #ai智能体）
3. **垂类**：#ai办公（二选一：#ai办公 #效率工具）
4. **人群/属性**：#零基础 #干货分享 #职场干货（按内容选 1-2 个）

## 五、"把 AI 养成你的员工"标题标签模板（直接套用）

### 模板 A：每日小技巧（对标小k）
**标题** = 一天一个workbuddy小技巧 + ，+ [禁止式/数字/结果三选一]
- 例：一天一个workbuddy小技巧，装完先别点这个按钮
- 例：一天一个workbuddy小技巧，3 个设置让 AI 记住你
- 例：一天一个workbuddy小技巧，让你学会自动整理桌面
**标签** = #workbuddy #ai #ai办公 #干货分享 #零基础

### 模板 B：清单排名（对标何公子/小k第12期）
**标题** = [禁止式开头] + ，+ 数字 + 个 + Skill/设置 + [好处]
- 例：WorkBuddy装完别直接用，先装这 8 个 skill
- 例：别乱装 skill，这 5 个装完效率翻倍
**标签** = #workbuddy #ai #ai工具 #skill #效率工具
